# 앱 단독 파일 확보 요구사항 재검토

## 완료 조건

사용자는 크롬을 직접 실행하거나 강의를 수동 재생하지 않는다. 앱에서 로그인하고 강의를 선택하면 파일 확보부터 로컬 전사까지 이어져야 한다. 수동 브라우저 재생에 의존하는 녹음은 이 요구사항의 성공으로 인정하지 않는다. 암호화된 오프라인 캐시만 저장되는 것도 전사 가능한 파일 확보 성공이 아니다.

## 공식 경로 조사

1. 원본/트랜스코딩 파일 다운로드 API: 서비스 운영자가 사용하는 기능이며 다운로드 권한과 기능 활성화가 필요하다. 현재 수강생 계정에 이 권한이 있다는 증거는 없다. 사용 가능한 다운로드 URL을 운영자가 제공하면 기존 다운로드·전사 파이프라인에 연결할 수 있다.
2. 수강생용 오프라인 다운로드: Kollus DRM 파일을 보관하여 지정 플레이어로 재생하는 기능이다. 일반 MP4/WAV 내보내기 또는 로컬 전사 입력을 제공한다고 확인되지 않았다.
3. 앱 내장 플레이어: Web Player Controller는 iframe 플레이어의 재생·진행·종료 이벤트와 제어를 지원한다. 브라우저 창을 사용자에게 직접 조작하게 하지 않는 구조의 후보지만, 미디어 파일 내보내기 API가 아니다. Windows 내장 웹 엔진과 해당 강의의 호환성, 오디오 확보, 자동 시작과 종료를 실측하기 전에는 해결책이라고 주장하지 않는다.

앱 내장 재생으로 일반 출력 녹음이 가능하더라도 실시간 재생 방식이며, 서버 파일 직접 다운로드와 구분하여 표시해야 한다. 브라우저 창을 숨기는 것만으로 파일 확보나 DRM 문제가 해결되지는 않는다.

## 현재 판정

앱 단독으로 전사 가능한 강의 파일을 확보하는 경로는 아직 검증되지 않았다. 20초 출력 녹음은 파일 저장에 성공했으나 음성 인식이 없었으므로 성공 증거가 아니다. 기존 UI와 합성 음성 전사 시험 결과는 핵심 완료 조건을 대체하지 않는다.

## 다음 검증의 통과 조건

- 앱이 정상 수강 인증으로 선택한 회차를 로드한다.
- 공식 플레이어의 실제 재생 진행과 종료를 확인한다.
- 사용자의 수동 브라우저 조작 없이 알아들을 수 있는 해당 강의 음성 파일을 얻는다.
- 파일에서 TXT/SRT/JSON이 생성되며 강의 내용과 대응함을 확인한다.
- 재생 실패, 무음, 취소는 성공으로 표시하지 않는다.
