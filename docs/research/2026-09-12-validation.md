# 2026-09-12 검증 상태

- 전체 자동 테스트: 50개 통과. Ruff 검사 통과.
- 실제 계정 로그인 및 데스크톱 앱에서 수강 목록 6개 표시 확인.
- 자체 제작한 한국어 합성 음성 WAV를 로컬 Whisper small로 실제 전사하여 TXT/SRT/JSON 생성 확인. 이는 실제 강의 녹음 성공을 의미하지 않는다.
- 영상 강의 4개의 첫 회차에서 Kollus 암호화 정책 확인. 일반 MP4 입력은 확인되지 않았다.
- 출력 장치 녹음, 녹음 후 전사, 취소 및 실패 시 원본 보존 경로 구현. 실제 강의의 녹음·전사는 아직 검증하지 못했다.
- 공식 Kollus 설치 파일의 Catenoid 서명 유효성 확인. 사용자의 진행 지시 후 설치 프로그램 실행 성공. 설치 위치 선택 화면에서 도구의 클릭·Enter 입력에 변화가 없어 사용자에게 해당 설치 단계 진행을 요청했다. 설치 완료는 아직 확인하지 못했으며, 설치만으로 보호된 오디오의 녹음을 보장할 수 없다.
- 제품 배포용 설치 파일은 아직 만들지 않았다.

## 설치 후 재생 확인

- 사용자의 설치 완료 안내 후 KollusAgent 및 KollusSvr 실행을 확인했다.
- 로그인된 Chrome에서 첫 강의 페이지를 열고 새로고침 및 회차 선택을 시도했다. 도구 스크린샷에는 검은 플레이어 영역만 보이며, 플레이어 프레임 조회는 시간 초과했다.
- 실제 사용자 화면도 검은지, 캡처만 제한되는지 아직 구분하지 못했다. 사용자에게 실제 영상·소리 여부를 요청했으며 재생 확인용 탭을 유지했다.
- 기본 출력 루프백은 Voicemeeter Input, 장치 77로 확인했다. 실제 강의 재생을 확인하지 못해 강의 녹음 성공으로 판단하지 않았다.
- 공식 진단 문서: https://docs.kollus.com/dev-guide/troubleshooting/end-users/environments/chrome-edge-pna/ (현재 문제의 확정 원인은 아님).

다음 검증: 실제 강의 재생 가능 여부와 정상 출력 녹음을 확인하고, 저장 파일의 음성 유효성 및 전사 결과를 확인한다.

## 실제 출력 녹음 시험

- 사용자 요청에 따라 장치 77 (Voicemeeter Input)에서 20초 녹음 실행.
- `.research/smoke/lecture-probe-01.wav` 저장 성공: 20초, 2채널 PCM16, peak 1386, RMS 약 117.03. 완전한 디지털 무음은 아니다.
- 이어서 로컬 Whisper small 전사를 실행했으나 인식된 음성이 없다는 오류로 종료했다. TXT/SRT/JSON 생성 성공이나 실제 강의 확보 성공으로 계산하지 않는다.
- 녹음 시점의 강의 발화 및 출력 경로가 확인되지 않아 오디오 보호 차단이라고 단정할 수 없다. 사용자에게 강사 목소리가 들리는 상태에서 재생 중이라고 알려 달라고 요청했다.
- 셸 프로세스 생성에서 Windows 오류 5 (접근 거부)가 간헐적으로 발생했고, 같은 명령 재시도에서 정상 실행됐다. Kollus가 원인이라는 증거는 없다.
